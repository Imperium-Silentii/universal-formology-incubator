# Инструкция: Рабочий цикл со-творца. Клонирование и правки

## 🧭 Назначение

Данный документ описывает основной рабочий цикл полноправного участника Институции. 

Ваша цель это не просто предложить стоящую идею, а **внести формальное изменение в тело нашего общего проекта**, которое будет рассмотрено, оценено и, в случае одобрения, интегрировано.

Это механизм вашего прямого воздействия на реальность Формологии.

---

## ⚖️ Правило участия

*   **Читать и клонировать** репозиторий может любой пользователь GitHub.
*   **Правки (Pull Request) к рассмотрению принимаются только от аккаунтов, обладающих статусом Сценического Гражданства.**

**Смысл правила:** Ваш вклад — это **актив**. Он должен быть подписан вашим Сценическим Именем, чтобы быть учтённым в общей экономике заслуг Институции. Анонимные предложения не токенизируются и не рассматриваются.

---

## 🛠️ Алгоритм действий

### Шаг 0. (Обязательный) Легитимация
Получите Сценическое Гражданство и титульное имя. Без этого шага функционал внесения правок для вас заблокирован.

[Инструкция по получению гражданства](https://github.com/Imperium-Silentii/universal-formology-incubator/edit/main/welcome/0003-scene-name.md)

### Шаг 1. Клонирование: Создание локальной копии мастерской
**Цель:** Получить на свой компьютер полную, живую копию всего репозитория для работы.

1.  На странице репозитория нажмите зелёную кнопку **`<> Code`**.
2.  Скопируйте URL.
3.  Откройте терминал на своём компьютере.
4.  Выполните команду, вставив скопированный URL:
    ```bash
    git clone https://github.com/your-username/universal-formology-incubator.git
    ```
    Теперь у вас есть локальная копия всей мастерской.

### Шаг 2. Внесение изменений: Работа в своей копии
**Цель:** Подготовить конкретное, изолированное улучшение.

1.  Создайте новую ветку для вашей правки. Это изолирует вашу работу:
    ```bash
    git checkout -b feature/name-of-your-contribution
    ```
2.  Внесите необходимые изменения в файлы в вашей локальной папке с помощью любого текстового редактора.
3.  Сохраните (зафиксируйте) ваши изменения с понятным описанием:
    ```bash
    git add .
    git commit -m "Описание внесённого улучшения или исправления"
    ```

### Шаг 3. Публикация и запрос на слияние (Pull Request)
**Цель:** Предложить ваши изменения к интеграции в основной проект.

1.  Отправьте вашу ветку в удалённый репозиторий:
    ```bash
    git push origin feature/name-of-your-contribution
    ```
2.  На странице репозитория на GitHub появится уведомление о новой ветке. Нажмите **`Compare & pull request`**.
3.  Заполните форму Pull Request (PR):
    *   **Title:** Чётко и ясно сформулируйте суть предложения.
    *   **Description:** Детально опишите, что вы изменили, какую проблему это решает и какую ценность несёт проекту.

### Шаг 4. Рецензирование и интеграция
Ваш PR будет рассмотрен руководством Институции. В процессе обсуждения вас могут попросить внести дополнительные правки. После одобрения ваш PR будет объединён (``merged``) с основной веткой проекта.

**Ваш вклад станет частью Универсальной Формологии.**
